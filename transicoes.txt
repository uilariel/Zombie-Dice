WELCOME
oq faz:
-> pega a read_line, separa todos os nomes e joga eles dentro de um vetor temporario
-> cria jogadores com os nomes q foram jogador pra dentro do vetor
-> embaralha esse vetor
-> transiciona

exibe:
mensagem de bem vindo e pedir pra inserir os nomes dos jogadores

WELCOME -> PREPARING MATCH
transicao: quando os nomes dos jogadores forem inseridos (getline)

WELCOME -> WELCOME
transicao: menos que 2 a mais que 6 jogadores foram inseridos
exib:numero invalido de jogadores

=====================================================================================
PREPARING MATCH
oq faz:
->apenas aguarda

exibe:
->exibe a ordem que os jogadores irao jogar 
->solicita que o usuario aperte enter pra continuar

PREPARING MATCH -> PLAYING
-> apertou <enter>
======================================================================================
PLAYING
oq faz:
-> apenas exibe na tela as opcoes e aguarda o input

exibe:
-> mensagem perguntando qual acao o jogador quer tomar
-> H = contabilizar oq foi pego e parar de jogar 
-> R = jogador o dado
-> Q = encerrar o jogo 

PLAYING -> HOLDING
transicao: input = H

PLAYING -> ROLLING
transicao: input = R

PLAYING -> QUITTING
transicao: input = Q 

==========================================================================================
QUITTING
oq faz: so seta o bool rodando como false e encerra o programa

exibe:
-> uma mensagem pedindo pro jogador digitar enter pra encerrar, mas vai encerrar
de qualquer jeito
===========================================================================================
HOLDING:
-> CHEGAR NESSE ESTADO INDICA QUE O USUARIO OPTOU POR CONTABILIZAR OS CEREBROS QUE ELE PEGOU AO INVEZ DE TENTAR JOGAR NOVAMENTE. A PARTIR DAQUI SABEMOS QUE DEVEMOS PEGAR OS CEREBROS ACUMULADOS E CONTABILIZAR NA STRUCT DO PLAYER.

oq faz:
->contabiliza os cerebros que foram acumulados
->reseta as variaveis temporarias que nao sao necessarias para zero
->muda pra turn result


exibe:
->Que cacada excelente!
->voce comeu x cerebros e tomou x tiros, parabens!

HOLDING -> TURN RESULT
transicao: input = empty()
============================================================================================
ROLLING
-> AQUI EH ONDE O JOGO ACONTECE. O JOGADOR DECIDIU RODAR O DADO. CHAMAR A FUNCAO DE ROLAR, CONTABILIZAR OQ CAIR EM CIMA DO Q TINHA ANTEORIORMENTE E A PARTIR DISSO DECIDIR SE O TURNO DELE ACABOU E ELE PERDEU OU SE ELE VAI TER
A CHANCE DE VOLTAR PARA O PLAYING E JOGAR NOVAMENTE.

oq faz: 
->rola os dados
->contabiliza tiros e cerebros temporarios
->encaminha o jogador pra lost ou playing.

exibir:
->quantidade que ele comeu no total
->tiros que recebeu

ROLLING -> LOST 
transicao: 3 ou mais tiros acumulados

ROLLING -> playing
transicao: menos de 3 tiros acumulados
=============================================================================================
LOST
-> AQUI O JOGADOR OPTOU POR ROLLING E ACABOU ACUMULANDO 3 TIROS 

oq faz:
->nao contabiliza nada
->reseta as variaveis temporarias 
->muda pra turn result

LOST -> TURN RESULT
transicao: acontece independente de qualquer coisa
==============================================================================================
TURN RESULT
-> AQUI O JOGADOR VEIO DO LOST OU DO HOLDING, ENTAO ELE JA TEVE OS
CEREBROS CONTABILIZADOS E AS VARIAVEIS RESETADAS
-> PRECISAMOS CHECAR SE HOUVE IMPATE, VITORIA E REGER O TURNO

oq faz:
->checa se houve impate ou vitoria
->incrementa turnos gerais se necessario
->passa pro proximo jogador.
